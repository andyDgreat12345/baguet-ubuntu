Start here / 从这里开始:
  1. Install Docker Engine + Compose v2 if needed.
     https://docs.docker.com/engine/install/ubuntu/
  2. In this folder run: bash Start.sh
  3. Open http://127.0.0.1:8766
  4. Save DeepSeek key → Prepare → Open WeChat → log in → open your chat → Read/Bind → Start.

Any account you control; one chosen chat. No spare account is required.
使用自己选择的微信账号；只在明确绑定的一个会话中自动工作。
